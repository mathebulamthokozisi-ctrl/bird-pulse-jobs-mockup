07 Non-Negotiable Rules
No Drift: The mockup must not drift from this UI Kit. If a component changes in index.html, this file must be updated in the same commit.
Backend-First: Every status, role, type, and metric must map to a real field in client-centric-stats. No invented data shapes.
Three Content Categories: (1) Real & surfaced — render faithfully. (2) Real but hidden/broken — annotate with <!-- [FIX PROPOSAL] -->. (3) New features — annotate with <!-- [NEW SUGGESTION] -->.
Undo/Redo: Use Git for all state management. Never manually delete code. Before risky changes, create a snapshot commit. To undo: git revert HEAD --no-edit.
Job Types (real values from JOB_TYPE_LABELS): repair · maintenance · install (Installation) · new_installation · new_build · reinstatement · supply_and_deliver · other. Never use "Electrical", "Plumbing", "HVAC" etc. as job types.
Job Nature (real values): to_be_done (To Be Done) · done_already (Done Already). No other values.
Assignment Roles (real values from JobAssignmentPanel.tsx): Tech Manager · Coordinator · Sales Rep · Job Owner. Job Owner must be one of Tech Manager or Coordinator.
