Document Editors Present in Mockup
  • Estimate Editor — Line item table organized by real cost categories (Materials, Equipment, Labour, Preliminaries, Travel, Subcontractor, Sundries).
  • Quote Editor — Header card (Bill To, Ship To, Details), editable line item table, sidebar sync.
  • Invoice Editor — Header card, editable line item table, sidebar sync.
  • Actual Costs Editor — Entry table (Date, Supplier, Category, Reference, Amount). Running total.
  • Jobcard Editor — Scope, Findings, Before Photos, Work Performed, After Photos, and dual signature capture (Technician & Client).
Editor UI Standards
  • All editors use .doc-editor which covers the screen with a white background.
  • Editor topbars have a solid white background (no amber gradients).
  • Cards inside editors use .de-card with overflow: visible to prevent clipping of multi-line content (textareas, signature canvases).
  • Scrollable tables inside cards MUST be wrapped in <div class="de-table-wrap"> to ensure border-radius is applied correctly without clipping the card body.
Other Modals
  • New Job Wizard — Client, Site, Description, Type, Nature, Priority, Requested Date, Reference.
  • Edit Job Modal — Same fields as New Job.
  • Team Assign Modal — Assignee list with selection state.
  • Bulk Status Modal — Status picker for selected jobs.

13 Non-Negotiable Rules Must be followed in every session
Rule Description
Mockup IS the standardindex.html is the design authority. Notes and UI Kit document it — not the other way around.
No driftDo not change the visual style unless explicitly requested. No new colours, fonts, or layout changes without instruction.
Snapshot before risky changesAlways create a git snapshot commit before large refactors.
No regressionNever remove or break a feature that was previously working.
White surfacesAll surfaces are white (#fff). Grey (#f0f2f5) is reserved for the canvas background only.
Left-align tablesAll table headers and cells are left-aligned.
Filters by inclusionUnchecked = show all. Checked = restrict to selection. Multiple in same group = OR. Multiple groups = AND.
Sync kit with mockupIf index.html changes, ui-kit.html must be updated in the same commit.
